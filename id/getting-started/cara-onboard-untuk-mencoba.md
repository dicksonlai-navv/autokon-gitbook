# Cara Onboard Untuk Mencoba

{% hint style="info" %}
Silakan [membuat janji panggilan penemuan](https://tidycal.com/dickson/unit-handover-inspection-demo-with-autokon) dengan kami untuk membahas tentang minat Anda melakukan percobaan bersama kami.
{% endhint %}

## Langkah 1: Pengaturan Proyek

Kami mengonfigurasi data proyek Anda dan mengonboard semua pengguna dengan akses login.

* Cakupan trial (unit, timeline, peran) dikonfirmasi dengan semua pihak.
* Membuat grup WhatsApp dengan PIC untuk koordinasi dan dukungan.
* [Informasi proyek](https://form.jotform.com/241931776009460) telah dimuat sebelumnya ke dalam sistem AutoKon.
* PIC Pengembang dan PIC Kontraktor menerima kredensial login.
* Detail kontak dari Tara (AI WhatsApp kami) akan dibagikan untuk pengelolaan cacat.

## Langkah 2: Lokakarya Online

Sebuah walkthrough langsung untuk melatih tim Anda tentang cara menggunakan AutoKon secara efektif.

* Sesi selama 1 jam dilakukan melalui Google Meets
* Walkthrough langsung dari fitur utama:
  * Penjadwalan Inspeksi
  * Logging Cacat Berbasis WhatsApp
  * Manajemen Alur Kerja Perbaikan Cacat
* Q & A terbuka untuk memastikan semua orang percaya diri sebelum percobaan dimulai

## Langkah 3: Mencoba Dimulai

Inspeksi unit nyata, logging cacat, dan pelacakan perbaikan dilakukan menggunakan AutoKon.

* Inspeksi unit nyata dijadwalkan menggunakan AutoKon
* Cacat dicatat di lokasi melalui WhatsApp oleh Inspektur
* Kontraktor mengakui tugas cacat dan menetapkan timeline perbaikan yang diharapkan
* Kontraktor mengunggah pembaruan perbaikan melalui WhatsApp
* AutoKon berfungsi sebagai platform pusat untuk semua jadwal inspeksi dan aktivitas perbaikan cacat

## Langkah 4: Monitoring & Dukungan

Kami memberikan dukungan real-time dan memantau penggunaan platform untuk memastikan pengalaman yang lancar.

* Kami menawarkan dukungan harian melalui grup WhatsApp dan onsite (jika diperlukan).
* Kami melacak penggunaan sistem dan merespons masalah secara real time.

## Langkah Terakhir: Ulasan Trial & Langkah Selanjutnya

Kami membahas bersama hasil trial dan selaras dengan langkah-langkah berikutnya untuk peluncuran atau peningkatan.

* Data trial dikompilasi: jumlah inspeksi, cacat, perbaikan, umpan balik pengguna
* Sesi debriefing diadakan untuk menyajikan hasil dan mengumpulkan input final
* Diskusi tentang opsi peluncuran, peningkatan sistem, atau kebutuhan integrasi
