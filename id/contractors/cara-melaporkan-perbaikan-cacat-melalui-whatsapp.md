# Cara Melaporkan Perbaikan Cacat Melalui WhatsApp

## Langkah 0: Cetak Laporan Inspeksi sebagai Referensi

Masuk ke WebApp AutoKon dan navigasikan ke menu **Manajemen Cacat > Ikhtisar** dari sidebar.

Pilih **unit(s)** yang relevan dan klik **"Ekspor ke PDF"** untuk mengunduh dan mencetak laporan inspeksi sebagai referensi selama perbaikan cacat.

{% hint style="info" %}
Cetak laporan inspeksi sebelumnya untuk dengan mudah mencocokkan tiap cacat dengan ID Cacat-nya.\
Ini juga membantu Anda untuk mengidentifikasi dengan akurat cacat yang memerlukan perbaikan di lokasi.
{% endhint %}

<figure><img src="../.gitbook/assets/Untitled design (3).png" alt=""><figcaption></figcaption></figure>

## Langkah 1: Buka & Aktifkan Bot

Buka obrolan WhatsApp Anda dengan AutoKon dan kirim **"Hi"** untuk mengaktifkan bot.

<figure><img src="../.gitbook/assets/AutoKon - How To Mockup (6).png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 2: Pilih Unit

Pilih **ID Unit** tempat Anda ingin mencatat perbaikan cacat.

<figure><img src="../.gitbook/assets/17.png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 3: Pilih ID Cacat

Pilih **ID Cacat** tempat Anda ingin mencatat perbaikan cacat.

{% hint style="info" %}
Tip: Cetak laporan inspeksi sebelumnya untuk dengan mudah mencocokkan tiap cacat dengan ID Cacat-nya.\
Ini juga membantu Anda untuk mengidentifikasi dengan akurat cacat yang memerlukan perbaikan di lokasi.
{% endhint %}

<figure><img src="../.gitbook/assets/18 (1).png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 4: Mengabadikan Perbaikan Cacat

Ambil **foto jelas dari perbaikan cacat** dan kirim dalam obrolan.

<figure><img src="../.gitbook/assets/19.png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah Terakhir: Melanjutkan atau Mengakhiri Sesi

Pilih untuk **mencatat cacat lain**, **mengganti unit**, atau **mengakhiri sesi**.

<figure><img src="../.gitbook/assets/20 (1).png" alt="" width="375"><figcaption></figcaption></figure>

✅ **Itu saja**! Perbaikan cacat berhasil dicatat dan akan muncul di dashboard Anda secara real-time. Pengembang real estat Anda juga akan diberi tahu tentang pengiriman Anda.
