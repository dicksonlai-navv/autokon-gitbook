# Cara Melog Perbaikan Cacat via WhatsApp

## Langkah 0: Cetak Laporan Inspeksi sebagai Referensi

Login ke AutoKon WebApp dan navigasikan ke menu **Pengelolaan Cacat > Ikhtisar** dari sidebar.

Pilih **unit** yang relevan dan klik **"Ekspor ke PDF"** untuk mengunduh dan mencetak laporan inspeksi sebagai referensi selama perbaikan cacat.

{% hint style="info" %}
Cetak laporan inspeksi terlebih dahulu untuk dengan mudah mencocokkan setiap cacat dengan ID Cacat-nya.\
Hal ini juga membantu Anda dengan akurat mengidentifikasi cacat yang memerlukan perbaikan di lokasi.
{% endhint %}

<figure><img src="../.gitbook/assets/Untitled design (3).png" alt=""><figcaption></figcaption></figure>

## Langkah 1: Buka & Aktifkan Bot

Buka percakapan WhatsApp Anda dengan AutoKon dan kirim **"Hai"** untuk mengaktifkan bot.

<figure><img src="../.gitbook/assets/AutoKon - How To Mockup (6).png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 2: Pilih Unit

Pilih **ID Unit** di mana Anda ingin melog perbaikan cacat.

<figure><img src="../.gitbook/assets/17.png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 3: Pilih ID Cacat

Pilih **ID Cacat** di mana Anda ingin melog perbaikan cacat.

{% hint style="info" %}
Tip: Cetak laporan inspeksi terlebih dahulu untuk dengan mudah mencocokkan setiap cacat dengan ID Cacat-nya.\
Hal ini juga membantu Anda dengan akurat mengidentifikasi cacat yang memerlukan perbaikan di lokasi.
{% endhint %}

<figure><img src="../.gitbook/assets/18 (1).png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 4: Tangkap Perbaikan Cacat

Ambil **foto jelas dari perbaikan cacat** dan kirimkan di percakapan.

<figure><img src="../.gitbook/assets/19.png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah Terakhir: Lanjutkan atau Akhiri Sesi

Pilih untuk **melog cacat lainnya**, **ganti unit**, atau **akhiri sesi**.

<figure><img src="../.gitbook/assets/20 (1).png" alt="" width="375"><figcaption></figcaption></figure>

✅ **Itu saja**! Perbaikan cacat berhasil dicatat dan akan muncul di dashboard Anda secara real-time. Pengembang real estat Anda juga akan diberitahu tentang pengajuan Anda.
