# Cara Mencatat Perbaikan Cacat via WhatsApp

## Langkah 0: Cetak Laporan Inspeksi untuk Referensi

Login ke AutoKon WebApp dan navigasi ke menu **Pengelolaan Cacat > Ikhtisar** dari sidebar.

Pilih **unit(s)** yang relevan dan klik **"Ekspor ke PDF"** untuk mengunduh dan mencetak laporan inspeksi sebagai referensi selama perbaikan cacat.

{% hint style="info" %}
Cetak laporan inspeksi sebelumnya untuk dengan mudah mencocokkan setiap cacat dengan ID Cacatnya.\
Ini juga membantu Anda mengidentifikasi dengan akurat cacat yang memerlukan perbaikan di lokasi.
{% endhint %}

<figure><img src="../.gitbook/assets/Untitled design (3).png" alt=""><figcaption></figcaption></figure>

## Langkah 1: Buka & Aktifkan Bot

Buka obrolan WhatsApp Anda dengan AutoKon dan kirim **"Hi"** untuk mengaktifkan bot.

<figure><img src="../.gitbook/assets/AutoKon - How To Mockup (6).png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 2: Pilih Unit

Pilih **Unit ID** tempat Anda ingin mencatat perbaikan cacat.

<figure><img src="../.gitbook/assets/17.png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 3: Pilih ID Cacat

Pilih **ID Cacat** tempat Anda ingin mencatat perbaikan cacat.

{% hint style="info" %}
Tip: Cetak laporan inspeksi sebelumnya untuk dengan mudah mencocokkan setiap cacat dengan ID Cacatnya.\
Ini juga membantu Anda mengidentifikasi dengan akurat cacat yang memerlukan perbaikan di lokasi.
{% endhint %}

<figure><img src="../.gitbook/assets/18 (1).png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 4: Ambil Foto Perbaikan Cacat

Ambil **foto yang jelas dari perbaikan cacat** dan kirimkan dalam obrolan.

<figure><img src="../.gitbook/assets/19.png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah Terakhir: Lanjut atau Akhiri Sesi

Pilih untuk **mencatat cacat lain**, **ubah unit**, atau **akhiri sesi**.

<figure><img src="../.gitbook/assets/20 (1).png" alt="" width="375"><figcaption></figcaption></figure>

✅ **Itu dia**! Perbaikan cacat berhasil dicatat dan akan muncul di dashboard Anda secara real-time. Pengembang real estate Anda juga akan diberi tahu tentang pengiriman Anda.
