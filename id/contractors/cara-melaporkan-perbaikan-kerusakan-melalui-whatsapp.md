# Cara Melaporkan Perbaikan Kerusakan melalui WhatsApp

## Langkah 0: Cetak Laporan Inspeksi untuk Referensi

Masuk ke WebApp AutoKon dan navigasi ke menu **Manajemen Kerusakan > Ikhtisar** dari sidebar.

Pilih **unit(s)** yang relevan dan klik **“Ekspor ke PDF”** untuk mengunduh dan mencetak laporan inspeksi sebagai referensi selama perbaikan kerusakan.

{% hint style="info" %}
Cetak laporan inspeksi terlebih dahulu untuk mudah mencocokkan setiap kerusakan dengan ID Kerusakannya.\
Hal ini juga membantu Anda mengidentifikasi dengan akurat kerusakan yang memerlukan perbaikan di lokasi.
{% endhint %}

<figure><img src="../.gitbook/assets/Untitled design (3).png" alt=""><figcaption></figcaption></figure>

## Langkah 1: Buka & Aktifkan Bot

Buka obrolan WhatsApp Anda dengan AutoKon dan kirim **“Hi”** untuk mengaktifkan bot.

<figure><img src="../.gitbook/assets/AutoKon - How To Mockup (6).png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 2: Pilih Unit

Pilih **ID Unit** dimana Anda ingin melaporkan perbaikan kerusakan.

<figure><img src="../.gitbook/assets/17.png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 3: Pilih ID Kerusakan&#x20;

Pilih **ID Kerusakan** dimana Anda ingin melaporkan perbaikan kerusakan.

{% hint style="info" %}
Tip: Cetak laporan inspeksi terlebih dahulu untuk mudah mencocokkan setiap kerusakan dengan ID Kerusakannya.\
Hal ini juga membantu Anda mengidentifikasi dengan akurat kerusakan yang memerlukan perbaikan di lokasi.
{% endhint %}

<figure><img src="../.gitbook/assets/18 (1).png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah 4: Lacak Perbaikan Kerusakan

Ambil **foto jelas dari perbaikan kerusakan** dan kirim di chat.

<figure><img src="../.gitbook/assets/19.png" alt="" width="375"><figcaption></figcaption></figure>

## Langkah Terakhir: Lanjutkan atau Akhiri Sesi

Pilih untuk **melaporkan kerusakan lain**, **mengubah unit**, atau **mengakhiri sesi**.

<figure><img src="../.gitbook/assets/20 (1).png" alt="" width="375"><figcaption></figcaption></figure>

✅ **Itu saja**! Perbaikan kerusakan berhasil dicatat dan akan muncul di dashboard Anda secara real-time. Pengembang real estat Anda juga akan diberitahu tentang pengiriman Anda.
