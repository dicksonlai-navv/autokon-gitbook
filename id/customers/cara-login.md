# Cara Login

## Langkah 1: Kunjungi Situs Web AutoKon

Anda dapat menggunakan Google Chrome, Microsoft Edge, Safari, atau browser lain yang Anda kenal.

Ketik alamat situs web yang diberikan kepada Anda di bilah alamat di bagian atas browser Anda, kemudian tekan **Enter**.

Situs web: [https://app.autokon.id/](https://app.autokon.id/)

{% hint style="info" %}
&#x20;Tip: Tandai halaman ini untuk akses mudah di lain waktu!
{% endhint %}

## Langkah 2: Masukkan Detail Login Anda

<figure><img src="../.gitbook/assets/6.png" alt="" width="375"><figcaption></figcaption></figure>

Anda akan melihat halaman login dengan dua bidang:

* **Email:** Ketik alamat email yang terdaftar dengan AutoKon.
* **Sandi:** Ketik sandi Anda dengan hati-hati. Sandi ini peka terhadap besar-kecil huruf.

## Langkah Terakhir: Klik Tombol "**Masuk**"

Setelah memasukkan detail Anda, klik tombol **Masuk**.

<figure><img src="../.gitbook/assets/7.png" alt="" width="375"><figcaption></figcaption></figure>

✅ **Anda berhasil masuk!** Anda sekarang harus melihat dashboard Anda.
