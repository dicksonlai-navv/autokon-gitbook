# Cara Login

## Langkah 1: Buka Website AutoKon

Anda dapat menggunakan Google Chrome, Microsoft Edge, Safari, atau browser lain yang Anda kenal.

Ketik alamat situs web yang diberikan kepada Anda ke dalam bilah alamat di bagian atas browser Anda, lalu tekan **Enter**.

Website: [https://app.autokon.id/](https://app.autokon.id/)

{% hint style="info" %}
&#x20;Tips: Tandai halaman untuk akses mudah lain kali!
{% endhint %}

## Langkah 2: Masukkan Detail Login Anda

<figure><img src="../.gitbook/assets/6.png" alt="" width="375"><figcaption></figcaption></figure>

Anda akan melihat halaman login dengan dua bidang:

* **Email:** Ketik alamat email yang didaftarkan dengan AutoKon.
* **Password:** Ketik password Anda dengan hati-hati. Ini sensitif terhadap huruf besar dan kecil.

## Langkah Terakhir: Klik Tombol “**Sign In”**

Setelah memasukkan detail Anda, klik tombol **Sign In**.

<figure><img src="../.gitbook/assets/7.png" alt="" width="375"><figcaption></figcaption></figure>

✅ **Anda masuk!** Anda sekarang harus melihat dasbor Anda.
